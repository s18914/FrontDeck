**WCAG** (Web Content Accessibility Guidelines) is the W3C standard for accessible web content. Its testable success criteria are grouped under four principles, **POUR**, and each criterion has a level: **A, AA or AAA**.

- **Perceivable** — information can be perceived: text alternatives for images, captions, enough contrast.
- **Operable** — the UI works with different inputs: full keyboard support, enough time to act, no flashing that can trigger seizures.
- **Understandable** — content and behavior are predictable: clear labels, helpful error messages, consistent navigation.
- **Robust** — it works with assistive technology: valid, semantic markup with correct names, roles and states.

Levels:

- **A** — the bare minimum.
- **AA** — the usual target; laws and contracts typically require it.
- **AAA** — the strictest; not expected for entire sites.

The current version is **WCAG 2.2**. Versions are backward compatible, so meeting 2.2 AA also meets 2.1 AA.
